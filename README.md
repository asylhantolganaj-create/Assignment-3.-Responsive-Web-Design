* **Task 0 (Responsive Typography):** Applied CSS media queries in `css/style.css` to change header font sizes for Mobile, Tablet, and Desktop screens.
* **Task 1 (Responsive Layout):** Created a 3-box container using pure CSS Flexbox and Media Queries:

  * **Tablet:** 2 boxes in the first row, 1 in the second row.
